# Ebooks gratuitos - Semana 39

| Recurso | URL | Por qué leerlo |
|---|---|---|
| The Rust Programming Language, capítulo 17: async y await | https://doc.rust-lang.org/book/ch17-00-async-await.html | Qué es un futuro, qué hace `.await` y por qué hace falta un runtime. La base de la teoría 01. |
| Tutorial de tokio | https://tokio.rs/tokio/tutorial | El runtime, las tareas y los canales de tokio, paso a paso. |
| Tokio: Unit Testing | https://tokio.rs/tokio/topics/testing | La guía oficial de los tests con tokio: `start_paused`, `pause` y el reloj en pausa, como en el lab 01. |
| Asynchronous Programming in Rust (Async Book) | https://rust-lang.github.io/async-book/ | Para profundizar: cómo funcionan los futuros por dentro y por qué importa `Send`. |
| Comprehensive Rust (Google), en español: async | https://google.github.io/comprehensive-rust/es/concurrency/async.html | Los fundamentos de async en español, con ejemplos cortos y una página sobre tokio. |

## Dinámica sugerida

- Capítulo 17 antes de la teoría 01 si async es nuevo para ti; la versión en español de Comprehensive Rust cubre lo mismo más corto.
- La guía de tests de tokio antes del lab 01.
- Async Book solo si quieres entender el error de `Send` de la teoría 02 por dentro.
