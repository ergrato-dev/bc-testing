# Videografía - Semana 37

Los videos usan versiones anteriores de Rust. Lo que se ve en ellos funciona igual en Rust 1.100.0; la salida de `cargo test` puede cambiar en detalles, como el número entre paréntesis después del nombre del hilo que entra en pánico.

| Recurso | URL | Por qué verlo |
|---|---|---|
| 20. Curso de RUST: TESTS | https://www.youtube.com/watch?v=mBajHMXtwcE | En español: el módulo de tests, `#[test]` y las macros de aserción, como en el lab 01. |
| Rust from Zero #9: testing - unit, integration & cargo test | https://www.youtube.com/watch?v=ewFOmQX7TsE | Repaso corto del capítulo 11 del libro: unitarios, integración y `cargo test`. |
| Writing and Running Tests - Rust Programming Tutorial #41 | https://www.youtube.com/watch?v=3Zg5-evaup0 | Un test desde cero y cómo leer la salida de `cargo test`. |
| Learn Rust: Writing Tests in Rust | https://www.youtube.com/watch?v=FM2-ErJrVcE | Aserciones con mensajes propios, `should_panic` y tests que devuelven `Result`, como en el lab 02. |
