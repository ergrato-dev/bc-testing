# Ebooks Free - Semana 10

| Recurso | URL | Por qué leerlo |
|---|---|---|
| Jest - Mock Functions (documentación oficial) | https://jestjs.io/docs/mock-functions | `mockImplementation`, `mockImplementationOnce`, `mock.calls` y mock parcial con `jest.requireActual`. |
| Mocks Aren't Stubs (Martin Fowler) | https://martinfowler.com/articles/mocksArentStubs.html | Artículo clásico sobre verificación de estado vs de comportamiento. |
| Test Double (Martin Fowler) | https://martinfowler.com/bliki/TestDouble.html | Definición corta de dummy, fake, stub, spy y mock. |
| But really, what is a JavaScript mock? (Kent C. Dodds) | https://kentcdodds.com/blog/but-really-what-is-a-javascript-mock | Construye un mock a mano y luego lo reemplaza por `jest.fn`, `jest.spyOn` y `jest.mock`. |
| JavaScript & Node.js Testing Best Practices (Yoni Goldberg) | https://github.com/goldbergyoni/javascript-testing-best-practices | Guía gratuita que recomienda stubs y spies frente a mocks para no acoplar los tests a la implementación. |
