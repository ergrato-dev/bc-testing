# Prácticas - Semana 03

Cuatro labs (4 h en total) sobre un mismo proyecto, `~/labs-semana-03`, que crea el lab 01. Cada lab copia sus archivos de `starter/` en esa carpeta y ejecuta solo sus tests con `pnpm test <nombre>`. Los labs no se entregan: el entregable es el [proyecto](../3-proyecto/README.md).

| Lab | Qué practicas | Tiempo |
|---|---|---|
| [Lab 01 - Primer proyecto con Jest](lab-01-primer-proyecto-jest/README.md) | `package.json`, pnpm, Jest, rojo y verde, error de ejecución, git y watch | 60 min |
| [Lab 02 - AAA y matchers](lab-02-aaa-y-matchers/README.md) | Tests con AAA y el matcher de cada tipo de valor | 60 min |
| [Lab 03 - De casos de prueba a tests](lab-03-de-casos-a-tests/README.md) | Los casos del planetario de la semana 2 como tests, y sus cuatro bugs | 70 min |
| [Lab 04 - Tests que mienten](lab-04-tests-que-mienten/README.md) | Mutaciones a mano y cinco tests en verde que no comprueban nada | 50 min |

Cada lab termina con una comprobación (`pnpm test` con `grep`) y una lista de repaso.
