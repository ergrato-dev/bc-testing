# Ebooks gratuitos - Semana 45

| Recurso | URL | Por qué leerlo |
|---|---|---|
| "Continuous Integration", de Martin Fowler | https://martinfowler.com/articles/continuousIntegration.html | El artículo de referencia sobre qué es integrar de forma continua y qué prácticas lo hacen posible (*build* automático, tests que se autocomprueban, arreglar el *build* roto antes que nada). La teoría 01 en su versión original. |
| Software Engineering at Google, capítulo 23: *Continuous Integration* | https://abseil.io/resources/swe-book/html/ch23.html | Cómo integra Google con miles de cambios al día: qué tests corren antes del *merge* y cuáles después, y qué hacer con los tests inestables. |
| Pro Git, *Customizing Git - Git Hooks* | https://git-scm.com/book/en/v2/Customizing-Git-Git-Hooks | Qué hooks tiene git y cuándo se ejecuta cada uno: lo que Husky y pre-commit instalan por ti. |
| ContinuousDelivery.com | https://continuousdelivery.com/ | El sitio de Jez Humble sobre entrega continua: la diferencia entre CI y CD, y los patrones de un *pipeline* de despliegue. |
| Documentación de GitHub Actions | https://docs.github.com/en/actions | El manual completo: sintaxis, eventos, runners, secretos y reutilización de workflows. |

## Dinámica sugerida

- El artículo de Fowler con la teoría 01.
- El capítulo de Google después de la teoría 03: compáralo con lo que hacen tus cinco workflows.
- El capítulo de Pro Git antes del lab 04.
