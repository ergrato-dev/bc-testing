# Ebooks gratuitos - Semana 23

| Recurso | URL | Por qué leerlo |
|---|---|---|
| Architecture Patterns with Python, cap. 2 "Repository Pattern" (Percival y Gregory) | https://www.cosmicpython.com/book/chapter_02_repository.html | El patrón repositorio con SQLAlchemy y cómo testearlo; lectura en línea gratuita. |
| SQLAlchemy Unified Tutorial | https://docs.sqlalchemy.org/en/21/tutorial/index.html | El tutorial oficial del estilo 2.0 (`select()`, `Session`), de principio a fin. |
| Test-Driven Development with Python (Percival) | https://www.obeythetestinggoat.com/ | Libro completo en línea; los capítulos de base de datos muestran tests de modelos y migraciones. |

## Dinámica sugerida

- Lee el capítulo 2 de *Architecture Patterns with Python* antes del lab 01.
- Consulta el *Unified Tutorial* cuando una consulta de SQLAlchemy no te quede clara.
