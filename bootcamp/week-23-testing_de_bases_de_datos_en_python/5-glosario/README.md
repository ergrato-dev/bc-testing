# Glosario Semana 23 - Testing de bases de datos en Python

## A

- **Alembic**: herramienta de migraciones de SQLAlchemy. Genera y aplica scripts que llevan el esquema de una versión a otra.
- **autogenerate**: modo de Alembic que compara los modelos con la base de datos y escribe la migración que falta.

## C

- **`CheckConstraint`**: restricción que la base de datos comprueba en cada fila, por ejemplo `stock >= 0`.
- **`command.check`**: función de Alembic que falla con `AutogenerateDiffsDetected` si los modelos no coinciden con las migraciones.

## D

- **`DataError`**: excepción de SQLAlchemy cuando el valor no cabe en el tipo de la columna, como un texto más largo que el `VARCHAR`.

## E

- **engine**: objeto de SQLAlchemy que sabe conectarse a una base de datos a partir de una URL.

## F

- **Factory Boy**: librería que crea objetos de prueba con valores por defecto; el test solo indica los que le importan.
- **Faker**: librería que genera datos realistas (nombres, correos, textos) por locale.
- **flush**: envío de los cambios pendientes de la sesión a la base de datos sin confirmar la transacción.

## I

- **`IntegrityError`**: excepción de SQLAlchemy cuando se viola una restricción (`UNIQUE`, `CHECK`, clave foránea).

## J

- **`join_transaction_mode="create_savepoint"`**: modo de la `Session` que convierte cada `commit()` y `rollback()` del código en operaciones sobre un savepoint, sin tocar la transacción externa.

## M

- **migración**: script versionado que cambia el esquema de la base de datos (`upgrade`) y lo revierte (`downgrade`).

## R

- **repositorio**: clase que encapsula las consultas a la base de datos de una entidad.
- **rollback por test**: patrón en el que cada test corre dentro de una transacción que se deshace al terminar.

## S

- **savepoint**: punto dentro de una transacción al que se puede volver sin deshacer la transacción entera.
- **`Sequence` (factory)**: declaración de Factory Boy que genera un valor distinto por objeto, útil para campos únicos.
- **Session**: unidad de trabajo de SQLAlchemy; acumula cambios y los envía en una transacción.
- **`SubFactory`**: declaración de Factory Boy que crea el objeto relacionado con otra factory.

## T

- **Testcontainers**: librería que arranca contenedores Docker desechables desde el código de los tests.
- **transacción externa**: la transacción que abre la fixture, por fuera de la que usa el código bajo prueba.
