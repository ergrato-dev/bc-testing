# Ebooks gratuitos - Semana 44

| Recurso | URL | Por qué leerlo |
|---|---|---|
| OWASP Top 10:2025 | https://top10.owasp.org/2025/ | El documento de la teoría 01: cada categoría con sus CWE, ejemplos de ataque y cómo prevenirla. |
| OWASP Web Security Testing Guide (WSTG) | https://owasp.org/www-project-web-security-testing-guide/stable/ | La guía de referencia para probar la seguridad de una aplicación web, organizada por áreas (autenticación, autorización, validación de entradas). Cada prueba tiene un identificador que puedes citar en el informe. |
| OWASP Application Security Verification Standard (ASVS) 5.0 | https://github.com/OWASP/ASVS/tree/master/5.0 | Los requisitos de seguridad que una aplicación debe cumplir, en tres niveles. Sirve para escribir los casos de abuso que faltan en tu proyecto. |
| OWASP Cheat Sheet Series | https://cheatsheetseries.owasp.org/ | Hojas cortas por tema. Las de esta semana: *SQL Injection Prevention*, *Cross Site Scripting Prevention*, *Insecure Direct Object Reference Prevention*, *Authorization Testing Automation* y *HTTP Headers*. |
| Building Secure and Reliable Systems (Google) | https://sre.google/books/building-secure-reliable-systems/ | El libro de Google sobre diseñar sistemas seguros; los capítulos de diseño para el mínimo privilegio y de pruebas de código son el contexto de las teorías 03 y 04. |

## Dinámica sugerida

- El Top 10 2025 con la teoría 01: lee la página de A01 y la de A05 entera.
- La cheat sheet de IDOR y la de *Authorization Testing Automation* antes del lab 02: la segunda propone la matriz de la teoría 03.
- La WSTG como consulta durante el proyecto: busca la prueba de cada test que escribes.
