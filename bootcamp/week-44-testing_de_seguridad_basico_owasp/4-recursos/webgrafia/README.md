# Webgrafía - Semana 44

| Recurso | URL | Para qué |
|---|---|---|
| ZAP: Baseline Scan | https://www.zaproxy.org/docs/docker/baseline-scan/ | Todas las opciones de `zap-baseline.py`, el formato del archivo de reglas y los códigos de salida (lab 03). |
| ZAP: Full Scan | https://www.zaproxy.org/docs/docker/full-scan/ | El escaneo activo del paso 5 del lab 03. |
| Go: vulnerability management | https://go.dev/doc/security/vuln/ | Cómo funciona la base de datos de Go y qué significa cada sección de la salida de `govulncheck`. |
| govulncheck | https://pkg.go.dev/golang.org/x/vuln/cmd/govulncheck | Opciones (`-show verbose`, `-format json`) y códigos de salida. |
| OSV-Scanner | https://google.github.io/osv-scanner/ | El escáner de Java de esta semana; también lee lockfiles de los demás lenguajes. |
| RustSec | https://rustsec.org/ | La base de datos de `cargo audit`, con un aviso por crate. |
| pnpm audit | https://pnpm.io/cli/audit | Opciones de `pnpm audit`: `--audit-level`, `--json`, `--fix` e ignorar avisos. |
| uv audit | https://docs.astral.sh/uv/reference/cli/#uv-audit | Opciones de `uv audit`: `--ignore`, `--ignore-until-fixed` y los formatos de salida. |
| OWASP Dependency-Check | https://owasp.org/www-project-dependency-check/ | El auditor clásico de Java del experimento del lab 04. |
| NVD: pedir una clave de la API | https://nvd.nist.gov/developers/request-an-api-key | La clave que necesita Dependency-Check. |
| `html/template` | https://pkg.go.dev/html/template | Cómo escapa según el contexto y qué hacen los tipos `template.HTML` que lo desactivan. |
| MDN: Content Security Policy | https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP | Cada directiva de la CSP de la teoría 04. |
| PortSwigger Web Security Academy: SQL injection | https://portswigger.net/web-security/sql-injection | Laboratorios gratuitos en el navegador con inyecciones más difíciles que la del lab 01 (ciega, por tiempo). |
| PortSwigger Web Security Academy: XSS | https://portswigger.net/web-security/cross-site-scripting | Lo mismo para XSS, incluidos los contextos de atributo y JavaScript. |
| PortSwigger Web Security Academy: IDOR | https://portswigger.net/web-security/access-control/idor | Variantes de IDOR: por id en la URL, en el cuerpo y en archivos estáticos. |
