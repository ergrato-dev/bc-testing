# Videografía - Semana 31

Si un video escribe `<argLine>` en Surefire sin `@{argLine}`, recuerda la trampa del [lab 02](../../2-practicas/lab-02-jacoco-umbral-y-reporte/README.md#paso-2-argline-paso-2).
