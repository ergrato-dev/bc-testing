# Webgrafía - Semana 46

|---|---|---|
| The Practical Test Pyramid (Ham Vocke) | https://martinfowler.com/articles/practical-test-pyramid.html | La pirámide con ejemplos de código de cada capa y un pipeline que las ejecuta. |
| TestPyramid (Martin Fowler) | https://martinfowler.com/bliki/TestPyramid.html | La idea original, en una página. |
| Just Say No to More End-to-End Tests (Google Testing Blog) | https://testing.googleblog.com/2015/04/just-say-no-to-more-end-to-end-tests.html | Por qué los tests E2E no sustituyen a los de las capas de abajo. |
| Test Sizes (Google Testing Blog) | https://testing.googleblog.com/2010/12/test-sizes.html | Pequeño, mediano y grande según lo que el test puede usar (red, base de datos): otra forma de clasificar capas. |

| Architectural Decision Records | https://adr.github.io/ | Plantillas y herramientas para escribir decisiones. |
| Adding a workflow status badge (GitHub) | https://docs.github.com/en/actions/how-tos/monitor-workflows/add-a-status-badge | La URL del *badge*, con rama o evento. |
| About READMEs (GitHub) | https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes | Dónde busca GitHub el README y cómo se enlazan otros archivos. |
| Make a README | https://www.makeareadme.com/ | Qué secciones lleva un buen README y por qué. |
| Jest: `coverageThreshold` | https://jestjs.io/docs/configuration | El umbral global y por archivo del lab 02. |
| `gh pr create` | https://cli.github.com/manual/gh_pr_create | `--fill`, `--base`, `--draft` y el resto de opciones. |
