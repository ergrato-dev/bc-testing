# Ebooks gratuitos - Semana 46

| Recurso | URL | Por qué leerlo |
|---|---|---|
| Software Engineering at Google, capítulos 11 a 14 | https://abseil.io/resources/swe-book | Cómo decide Google qué tamaño de test usar, qué hace un buen test unitario y cuándo merecen la pena los tests más grandes. Las secciones 3 y 4 de tu estrategia a escala de miles de ingenieros. |
| Site Reliability Engineering, capítulo 17: *Testing for Reliability* | https://sre.google/sre-book/testing-reliability/ | Las pruebas vistas desde quien opera el sistema: qué se prueba antes de una versión y qué después. Contexto para la fila «a mano» de tu estrategia. |
| Pro Git, sección 2.6: *Tagging* | https://git-scm.com/book/en/v2/Git-Basics-Tagging | Etiquetas ligeras y anotadas, y cómo subirlas: el paso 8 del proyecto. |
| Testing Microservices, de Toby Clemson | https://martinfowler.com/articles/microservice-testing/ | Una estrategia completa para un sistema con varios servicios, capa por capa, con el riesgo que cubre cada una. El museo, con cuatro APIs del mismo dominio, se le parece. |
