# Ebooks Free - Semana 18

| Recurso | URL | Por qué leerlo |
|---|---|---|
| unittest.mock - getting started (documentación oficial) | https://docs.python.org/3/library/unittest.mock-examples.html | Guía gratuita con ejemplos de `patch`, `side_effect`, `call_args_list` y autospec. |
| Architecture Patterns with Python - Cap. 3: On Coupling and Abstractions | https://www.cosmicpython.com/book/chapter_03_abstractions.html | Libro libre online: por qué depender de abstracciones inyectadas reduce la necesidad de `mock.patch`. |
| Mocks Aren't Stubs (Martin Fowler) | https://martinfowler.com/articles/mocksArentStubs.html | Artículo clásico sobre verificación de estado frente a verificación de comportamiento. |

> Prioriza los capítulos donde se discute el diseño de tests, no solo la API de mocks.
