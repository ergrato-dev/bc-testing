# Proyecto Semana 08 - Suite Parametrizada con Jest

## Objetivo

Construir una suite de tests del dominio asignado usando matchers adecuados y parametrización con `test.each`.

## Entregable obligatorio

- Suite en JavaScript/Jest.
- Mínimo 10 tests ejecutables.
- Al menos 2 bloques con `test.each`.

## Reglas del proyecto

1. Usa solo JavaScript y Jest.
2. Mantiene nomenclatura técnica en inglés.
3. Usa comentarios y explicaciones en español en la documentación de entrega.
4. No uses dominio de ejemplo prohibido por política anticopia.

## Requisitos técnicos mínimos

- Casos válidos, inválidos y límite.
- Matchers específicos y legibles.
- Parametrización con tablas de casos.
- Sin servicios externos reales.

## Estructura starter

- `starter/item-pricing.service.test.js`

> La carpeta `solution/` del proyecto se mantiene fuera del repositorio público.
