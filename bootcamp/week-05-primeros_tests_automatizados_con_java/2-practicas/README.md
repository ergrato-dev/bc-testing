# Prácticas - Semana 05

Cuatro labs (4 h en total) sobre un mismo proyecto Maven, `~/labs-semana-05`, que crea el lab 01. Son los labs de la [semana 3](../../week-03-primeros_tests_automatizados_con_javascript/2-practicas/README.md) y la [semana 4](../../week-04-primeros_tests_automatizados_con_python/2-practicas/README.md) en Java: mismo código, mismos casos y mismos bugs, para que te fijes en lo que cambia. Cada lab copia sus archivos de `starter/` en esa carpeta y ejecuta solo sus tests con `mvn test -Dtest=<Clase>`. Los labs no se entregan: el entregable es el [proyecto](../3-proyecto/README.md).

| Lab | Qué practicas | Tiempo |
|---|---|---|
| [Lab 01 - Primer proyecto con Maven](lab-01-primer-proyecto-maven/README.md) | `pom.xml` a mano, error de compilación, rojo y verde, códigos de salida y git | 60 min |
| [Lab 02 - AAA y assertions](lab-02-aaa-y-assertions/README.md) | Tests con AAA y la comprobación de cada tipo de valor, delta y AssertJ incluidos | 60 min |
| [Lab 03 - De casos de prueba a tests](lab-03-de-casos-a-tests/README.md) | Los casos del planetario de la semana 2 en clases `@Nested`, y sus cuatro bugs | 70 min |
| [Lab 04 - Tests que mienten](lab-04-tests-que-mienten/README.md) | Mutaciones a mano y cinco tests en verde que no comprueban nada | 50 min |

Cada lab termina con una comprobación (`mvn test` con `grep`) y una lista de repaso.
