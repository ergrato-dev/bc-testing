# Videografía - Semana 05

Muchos vídeos crean el proyecto desde el IDE o con JUnit 5. En el curso el `pom.xml` se escribe a mano ([teoría 01](../../1-teoria/01-setup-junit.md#pomxml)) y se ejecuta con `mvn test`; la API Jupiter que muestran (`@Test`, `assertEquals`, `assertThrows`) es la misma en JUnit 6.

## En español

| Vídeo | Canal | Para qué |
|---|---|---|
| [Pruebas unitarias en Java con JUnit desde cero](https://www.youtube.com/watch?v=-3Ch6YGdaYA) | Sin Rueda Tecnológica | Primeros tests con JUnit, antes del lab 01 |
| [Cómo crear tests unitarios con JUnit 5](https://www.youtube.com/watch?v=08Nd8A3M8oU) | makigas | Una clase de test paso a paso, como refuerzo de la teoría 02 |
| [Cómo hacer tests de excepciones en JUnit 5 con assertThrows](https://www.youtube.com/watch?v=0By889o7JLM) | makigas | `assertThrows` y el mensaje del error, junto a la teoría 03 |
| [Java parte 152. Pruebas unitarias con JUnit 5](https://www.youtube.com/watch?v=RmCGR5anOkE) | El laboratorio de Rafa | Repaso de conceptos; primera de una serie que llega a cobertura |
