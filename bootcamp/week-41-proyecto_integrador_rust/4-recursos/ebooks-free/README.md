# Ebooks gratuitos - Semana 41

| Recurso | URL | Por qué leerlo |
|---|---|---|
| The Rust Programming Language, cap. 11.3 | https://doc.rust-lang.org/book/ch11-03-test-organization.html | Unitarios en `src/` y tests de integración en `tests/`: la base de las capas de la teoría 01. |
| Rust by Example - Testing | https://doc.rust-lang.org/rust-by-example/testing.html | Unitarios, doctests, tests de integración y dependencias de desarrollo, con ejemplos cortos para repasar la etapa. |
| The Cargo Book | https://doc.rust-lang.org/cargo/ | Qué hace cada comando de `verify.sh` (`cargo test --doc`, `--benches`, `--no-fail-fast`) y cómo se declaran los targets. |

## Dinámica sugerida

- El capítulo 11.3 del libro antes del lab 01, para tener claro qué es un test de integración en Rust.
- Rust by Example como repaso de la etapa antes de la presentación.
- El Cargo Book como consulta durante el paso 2 del proyecto.
