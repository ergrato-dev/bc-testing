# Ebooks y Lecturas Gratuitas

## Selección recomendada

| Recurso | URL | Por qué leerlo |
| --- | --- | --- |
| Express - Error Handling (guía oficial) | https://expressjs.com/en/guide/error-handling.html | Explica el middleware de errores `(err, req, res, next)`, clave para devolver status y bodies de error predecibles y testeables. |
| RFC 9110 - HTTP Semantics (sección 15, Status Codes) | https://www.rfc-editor.org/rfc/rfc9110.html#name-status-codes | La especificación oficial y gratuita de cada código de estado; la fuente final para decidir qué status debe afirmar un test. |
| Consumer-Driven Contracts - Martin Fowler (Ian Robinson) | https://martinfowler.com/articles/consumerDrivenContracts.html | Artículo clásico sobre contratos entre servicios y cómo evolucionar una API sin romper a sus consumidores. |
| JavaScript Testing Best Practices - Yoni Goldberg (sección Backend Testing) | https://github.com/goldbergyoni/javascript-testing-best-practices | Guía libre con buenas prácticas de tests de componentes, contratos y middlewares en APIs Node.js. |

## Enfoque de lectura

- Contratos HTTP consistentes.
- Estrategias de pruebas de endpoint repetibles.
- Manejo de errores en APIs orientadas a dominio.
