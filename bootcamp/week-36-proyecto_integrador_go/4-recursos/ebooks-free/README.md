# Ebooks gratuitos - Semana 36

| Recurso | URL | Por qué leerlo |
|---|---|---|
| Software Engineering at Google, cap. 11: Testing Overview | https://abseil.io/resources/swe-book/html/ch11.html | Tamaños de test (pequeño, mediano, grande) según lo que arrancan, y por qué una suite rápida se ejecuta más veces. Es el criterio que separa las fases de `verify.sh`. |
| Software Engineering at Google, cap. 14: Larger Testing | https://abseil.io/resources/swe-book/html/ch14.html | Qué riesgos solo ven los tests grandes (configuración, integración con dependencias reales) y cuánto cuestan. Ayuda a escribir la sección de riesgos del reporte. |
| Learn Go with Tests: Intro to acceptance tests | https://quii.gitbook.io/learn-go-with-tests/testing-fundamentals/intro-to-acceptance-tests | Un test que arranca el programa entero y lo prueba desde fuera: el test de extremo a extremo que el reporte del museo propone como próximo paso. |

## Dinámica sugerida

- Capítulo 11 antes del lab 01.
- Capítulo 14 antes del paso 5 del proyecto (riesgos y huecos).
