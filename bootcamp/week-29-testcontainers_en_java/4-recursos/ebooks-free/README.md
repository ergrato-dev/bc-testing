# Ebooks gratuitos - Semana 29

| Recurso | URL | Por qué leerlo |
|---|---|---|
| PostgreSQL 18 Documentation (PDF, A4) | https://www.postgresql.org/files/documentation/pdf/18/postgresql-18-A4.pdf | El manual completo de la versión que usan la aplicación y los tests. Lee los capítulos de restricciones (*Constraints*) e `INSERT ... ON CONFLICT`. |
| PostgreSQL Error Codes (apéndice A) | https://www.postgresql.org/docs/18/errcodes-appendix.html | La lista de SQLState: `23505`, `23514`, `42601` y el resto, con su nombre. |
| Flyway Documentation | https://documentation.red-gate.com/fd | Referencia de Flyway: nombres de migraciones, `flyway_schema_history`, validación y configuración. |

## Dinámica sugerida

- Consultar el apéndice de códigos de error durante el lab 02.
- Leer la parte de migraciones versionadas de Flyway antes del paso 3 del proyecto.
