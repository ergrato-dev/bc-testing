# Videografía - Semana 29

Los videos están en inglés y usan Spring Boot 3 y Testcontainers 1.x. Lo que cambia con las versiones del curso: los artefactos de Testcontainers 2 llevan el prefijo `testcontainers-` y `PostgreSQLContainer` se importa de `org.testcontainers.postgresql` ([teoría 01](../../1-teoria/01-testcontainers-y-el-ciclo-de-vida.md#las-dependencias)); `@ServiceConnection` y `@TestConfiguration` funcionan igual.

| Recurso | URL | Por qué verlo |
|---|---|---|
| Testcontainers and Spring Boot from integration tests to local development! - Oleg Šelajev (Spring I/O) | https://www.youtube.com/watch?v=7rTs3e79sDo | Oleg Šelajev, de AtomicJar, la empresa que creó Testcontainers, muestra cómo se integra con Spring Boot, desde los tests de integración hasta el desarrollo en local. |
| Spring Boot Testcontainers - Integration Testing made easy! (Dan Vega) | https://www.youtube.com/watch?v=erp-7MCK5BU | Un PostgreSQL de Testcontainers en los tests con el soporte que añadió Spring Boot 3.1, el de `@ServiceConnection`. |
