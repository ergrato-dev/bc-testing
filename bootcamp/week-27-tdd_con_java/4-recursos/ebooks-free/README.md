# Ebooks gratuitos - Semana 27

| Recurso | URL | Por qué leerlo |
|---|---|---|
| Test-Driven Development: Extensive Tutorial (Grzegorz Gałęzowski) | https://github.com/grzesiek-galezowski/tdd-ebook | Libro gratuito sobre TDD orientado a objetos: cómo los tests llevan a interfaces y a objetos que colaboran, la idea de la [teoría 03](../../1-teoria/03-outside-in-con-mockito.md). Se lee en línea o se descarga en EPUB y PDF desde Leanpub. |
| ArchUnit User Guide | https://www.archunit.org/userguide/html/000_Index.html | La guía oficial: todas las reglas de la [teoría 04](../../1-teoria/04-archunit-fitness-functions.md), las capas, los ciclos entre paquetes y `FreezingArchRule`. |
| IntelliJ IDEA Reference Card (PDF) | https://resources.jetbrains.com/storage/products/intellij-idea/docs/IntelliJIDEA_ReferenceCard.pdf | Una página con todos los atajos del keymap por defecto. Imprímela para la semana. |

## Dinámica sugerida

- Ten la Reference Card a mano durante los labs 01 y 02.
- Lee la parte 1 del libro de Gałęzowski después del lab 03.
- Consulta la guía de ArchUnit cuando escribas las reglas del proyecto.
