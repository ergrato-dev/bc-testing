# Ebooks y Lecturas Gratuitas

## Selección recomendada

| Recurso | URL | Por qué leerlo |
| --- | --- | --- |
| Effective Snapshot Testing - Kent C. Dodds | https://kentcdodds.com/blog/effective-snapshot-testing | Cuándo aportan valor los snapshots, por qué evitar los gigantes y cómo usar serializers y diffs para que sean revisables. |
| fast-check - Why Property-Based? | https://fast-check.dev/docs/introduction/why-property-based/ | Explica qué gana property-based testing frente a los tests por ejemplos: casos borde y bugs que nadie escribió a mano. |
| fast-check - Quick Start | https://fast-check.dev/docs/tutorials/quick-start/ | Tutorial oficial que incluye cómo interpretar el contraejemplo y la seed que fast-check imprime al fallar. |
| Choosing properties for property-based testing - Scott Wlaschin | https://fsharpforfunandprofit.com/posts/property-based-testing-2/ | Siete patrones para descubrir propiedades (ida y vuelta, invariantes, idempotencia, oráculo) aplicables a cualquier lenguaje. |

## Enfoque de lectura

- Criterios para snapshots mantenibles.
- Diseño de invariantes de negocio.
- Diagnóstico de contraejemplos minimizados (shrinking) y reproducción con seed.
