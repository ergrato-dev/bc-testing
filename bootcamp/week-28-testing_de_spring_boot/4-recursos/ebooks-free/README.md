# Ebooks gratuitos - Semana 28

| Recurso | URL | Por qué leerlo |
|---|---|---|
| Spring Framework Reference: Testing | https://docs.spring.io/spring-framework/reference/testing.html | El manual completo del TestContext Framework: la caché de contextos, `@MockitoBean`, `@TestBean`, `MockMvc`, `MockMvcTester` y `RestTestClient`. Es la fuente de las teorías 01, 02 y 04. |
| Hibernate Validator Reference Guide (PDF) | https://docs.jboss.org/hibernate/stable/validator/reference/en-US/pdf/hibernate_validator_reference.pdf | Todas las restricciones de Bean Validation (`@NotBlank`, `@Email`, `@Min`), cómo se escriben los mensajes y cómo se traducen, lo que viste en el lab 02. |
| RFC 9457: Problem Details for HTTP APIs | https://www.rfc-editor.org/rfc/rfc9457 | El estándar de `ProblemDetail`: qué significan `type`, `title`, `status`, `detail` e `instance`. Corto: se lee en media hora. |

## Dinámica sugerida

- Lee el apartado "MockMvc" del manual de Spring antes del lab 01, y "AssertJ Integration" antes del lab 02.
- Consulta la guía de Hibernate Validator cuando elijas las restricciones de los records del proyecto.
- Lee la RFC 9457 antes de decidir los códigos de error de tu API (paso 3 del proyecto).
