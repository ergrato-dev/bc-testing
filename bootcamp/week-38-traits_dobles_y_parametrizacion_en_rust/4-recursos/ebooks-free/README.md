# Ebooks gratuitos - Semana 38

| Recurso | URL | Por qué leerlo |
|---|---|---|
| The Rust Programming Language, capítulo 10.2: Traits | https://doc.rust-lang.org/book/ch10-02-traits.html | Cómo se declara un trait, cómo se implementa con `impl Trait for Tipo` y qué son `impl Trait` y los *trait bounds* (`<R: Registry>`). La base de la teoría 01. |
| The Rust Programming Language, capítulo 18.2: objetos de trait | https://doc.rust-lang.org/book/ch18-02-trait-objects.html | `Box<dyn Trait>` para guardar tipos distintos en una misma lista, y la diferencia entre despacho estático y dinámico. |
| The Rust Programming Language, capítulo 15.5: `RefCell` | https://doc.rust-lang.org/book/ch15-05-interior-mutability.html | La mutabilidad interior. El ejemplo del capítulo es un mock escrito a mano que guarda mensajes desde `&self`: el mismo problema que el fake del lab 01. |
| The Rust Programming Language, capítulo 11.3: organización de los tests | https://doc.rust-lang.org/book/ch11-03-test-organization.html | Por qué el código compartido va en `tests/common/mod.rs` y no en `tests/common.rs`. |
| Comprehensive Rust (Google), en español: `dyn Trait` | https://google.github.io/comprehensive-rust/es/generics/dyn-trait.html | Genéricos frente a `dyn Trait` en español, con un ejemplo corto de cada uno. |

## Dinámica sugerida

- Capítulos 10.2 y 18.2 antes de la teoría 01 si los traits son nuevos para ti.
- Capítulo 15.5 antes del lab 01.
- Capítulo 11.3 antes del lab 04.
