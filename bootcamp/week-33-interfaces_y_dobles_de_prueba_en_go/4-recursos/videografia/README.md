# Videografía - Semana 33

Los videos usan versiones anteriores de Go y de las librerías. Dos diferencias con lo que ves en los labs: si un video importa `github.com/golang/mock/gomock`, hoy es `go.uber.org/mock/gomock`, el mismo API con otro nombre; y si instala mockgen con `go install`, en esta semana se registra con `go get -tool` y se ejecuta con `go tool mockgen` ([teoría 02](../../1-teoria/02-mockgen-y-testify.md#1-mockgen-como-herramienta-del-módulo)).

|---|---|---|
| Golang: pruebas unitarias en la lógica de negocios | https://www.youtube.com/watch?v=MhdyRcdcRZ0 | En español: interfaces sustituidas por dobles para probar la lógica de negocio, como en el lab 01. |
| Generating Mocks for Testing in Go with Gomock | https://www.youtube.com/watch?v=7TXmeW_S5fw | mockgen y `EXPECT()` desde cero, el lab 02. |
| Testing with golang and testify - tutorial part 1 | https://www.youtube.com/watch?v=Su6zn1_blw0 | `assert` y `require` con ejemplos, el inicio del lab 03. |
| Testing with golang and testify - mocking - tutorial part 3 | https://www.youtube.com/watch?v=A1eR7TxeGcE | Un mock con `testify/mock`, `On` y `AssertExpectations`, el PASO 3 del lab 03. |
