# Webgrafía - Semana 40

| Recurso | URL | Para qué |
|---|---|---|
| proptest en docs.rs | https://docs.rs/proptest/1.12.0/proptest/ | Las estrategias de cada tipo, `ProptestConfig` y las macros. |
| cargo-fuzz | https://github.com/rust-fuzz/cargo-fuzz | Los subcomandos (`init`, `run`, `tmin`, `cmin`, `coverage`) y sus opciones. |
| Opciones de libFuzzer | https://llvm.org/docs/LibFuzzer.html | Todo lo que va después de `--` en `cargo fuzz run`: `-max_total_time`, `-runs`, `-max_len`. |
| criterion en docs.rs | https://docs.rs/criterion/0.8.2/criterion/ | `Criterion`, `BenchmarkGroup`, `Throughput` y la configuración de cada medición. |
| cargo-llvm-cov | https://github.com/taiki-e/cargo-llvm-cov | Formatos de informe, `--fail-under-*`, doctests y ramas en nightly. |
| cargo-nextest | https://nexte.st/ | Perfiles, reintentos de tests inestables y por qué no ejecuta los doctests. |
| Lista de lints de clippy | https://rust-lang.github.io/rust-clippy/master/index.html | Cada aviso con su explicación y su grupo, para decidir si se corrige o se permite con `#[allow]`. |

## Dinámica sugerida

- La página de libFuzzer durante el lab 02, para las opciones.
- La lista de clippy abierta durante el paso 5 del lab 04.
- La documentación de cargo-llvm-cov antes del paso 6 del proyecto.
