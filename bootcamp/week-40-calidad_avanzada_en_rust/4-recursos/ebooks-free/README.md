# Ebooks gratuitos - Semana 40

| Recurso | URL | Por qué leerlo |
|---|---|---|
| Proptest Book | https://proptest-rs.github.io/proptest/ | El libro oficial de proptest: estrategias, `prop_compose!`, reducción y el archivo de regresiones. La base de la teoría 01. |
| Rust Fuzz Book | https://rust-fuzz.github.io/book/ | cargo-fuzz paso a paso, con un tutorial sobre un crate real y fuzzing estructurado con `Arbitrary`. |
| Criterion.rs User Guide | https://bheisler.github.io/criterion.rs/book/ | Cómo mide criterion, qué significa cada línea de su salida y cómo comparar con líneas base. |
| cargo-mutants | https://mutants.rs/ | El manual de cargo-mutants: qué mutantes genera, cómo filtrarlos y cómo leer `mutants.out/`. |
| The Rust Performance Book | https://nnethercote.github.io/perf-book/ | Para después del lab 03: cómo medir y qué optimizar en Rust. |

## Dinámica sugerida

- Proptest Book antes del lab 01; las secciones de estrategias, durante el paso 3 del proyecto.
- El tutorial del Rust Fuzz Book antes del lab 02.
- El capítulo de análisis de la guía de criterion después del lab 03, para entender `p` y el umbral de ruido.
- mutants.rs durante el lab 04 y el paso 7 del proyecto.
