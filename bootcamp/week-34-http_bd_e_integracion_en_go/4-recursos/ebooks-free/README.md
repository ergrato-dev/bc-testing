# Ebooks gratuitos - Semana 34

| Recurso | URL | Por qué leerlo |
|---|---|---|
| Learn Go with Tests: HTTP Server | https://quii.gitbook.io/learn-go-with-tests/build-an-application/http-server | Una API construida con TDD a base de `httptest.NewRequest` y `NewRecorder`, con un almacén falso detrás, como el lab 01. |
| Learn Go with Tests: Context | https://quii.gitbook.io/learn-go-with-tests/go-fundamentals/context | Cómo se cancela el trabajo de un handler cuando el cliente se va, y cómo se prueba con un spy. Es la base del paso 2 del proyecto. |
| Writing Web Applications | https://go.dev/doc/articles/wiki/ | El tutorial oficial de `net/http`: handlers, rutas y plantillas, para quien no ha escrito antes un servidor en Go. |

## Dinámica sugerida

- *Writing Web Applications* antes del lab 01, si `net/http` es nuevo para ti.
- *HTTP Server* después del lab 01, para comparar sus tests con los tuyos.
- *Context* antes del paso 2 del proyecto.
