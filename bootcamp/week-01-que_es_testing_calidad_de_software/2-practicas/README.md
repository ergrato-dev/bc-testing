# Prácticas - Semana 01

Cuatro labs (4 h en total) sin código: se trabaja con tablas y reportes en Markdown, en una carpeta `~/labs-semana-01` que crea el lab 01. Los labs no se entregan: el entregable es el [proyecto](../3-proyecto/README.md).

| Lab | Qué practicas | Tiempo |
|---|---|---|
| [Lab 01 - Calidad y niveles](lab-01-calidad-y-niveles/README.md) | Dimensiones de calidad, nivel de cada test, pirámide o cono, manual o automatizado | 60 min |
| [Lab 02 - Análisis de reportes](lab-02-analisis-de-reportes/README.md) | Revisar y corregir cinco reportes; severidad y prioridad justificadas | 60 min |
| [Lab 03 - Del mensaje al reporte](lab-03-del-mensaje-al-reporte/README.md) | Convertir el mensaje de un usuario en un reporte y preguntarle lo que falta | 50 min |
| [Lab 04 - Triage y ciclo de vida](lab-04-triage-y-ciclo-de-vida/README.md) | Decidir el destino de siete reportes y seguir uno por todos sus estados | 70 min |

Cada lab trae en `starter/` el archivo que rellenas. Termina con un `grep` que cuenta lo que queda por rellenar y una lista de comprobación.

## Antes de empezar

Necesitas una terminal (en Windows, la de WSL o Git Bash) y un editor de texto. Comprueba que tienes `grep`:

```bash
grep --version | head -1
# grep (GNU grep) 3.7
```

La versión puede ser otra. Si el comando no existe, usa la terminal de WSL o Git Bash.
