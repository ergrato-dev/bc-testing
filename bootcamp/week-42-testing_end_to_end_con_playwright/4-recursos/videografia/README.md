# Videografía - Semana 42

Videos del canal oficial de Playwright, en inglés y cortos (de 5 a 15 minutos).

| Recurso | URL | Por qué verlo |
|---|---|---|
| Playwright for Beginners: Install and run tests using the CLI | https://www.youtube.com/watch?v=SLhz2KmBh2Q | La instalación, la configuración y las opciones de `playwright test` del lab 01. |
| Handling Visibility in Playwright: getByText vs. getByRole | https://www.youtube.com/watch?v=4w0W8qYub2U | Por qué `getByRole` no encuentra lo oculto y `getByText` sí: el detalle que explica el tooltip del lab 02. |
| Playwright Assertions: Avoid Race Conditions with This Simple Fix! | https://www.youtube.com/watch?v=1VxkHP8vfGg | El Experimento 1 del lab 02 explicado: `expect(await ...)` frente a `await expect(...)`. |
| How to trigger flaky Playwright tests locally after they fail on CI | https://www.youtube.com/watch?v=0dHDmSjx55o | Cómo reproducir en tu equipo un test que falla a veces, para después del lab 04. |
| Get started with end-to-end testing: Playwright, episodio 5: Debugging Tests (Visual Studio Code) | https://www.youtube.com/watch?v=oYCSzYG-Bbg | Depurar con el trace viewer y la extensión de VS Code: lo que el lab 04 hace desde la terminal. |

- El de instalación antes del lab 01.
