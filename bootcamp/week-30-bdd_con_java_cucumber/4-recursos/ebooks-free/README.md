# Ebooks gratuitos - Semana 30

No hay un libro gratuito y actual de Cucumber para Java: los de referencia (*The Cucumber for Java Book*, *BDD in Action*) son de pago. La documentación oficial cubre lo mismo y está al día con Cucumber 8. Léela como un libro, en este orden:

| Recurso | URL | Por qué leerlo |
|---|---|---|
| Cucumber — 10 minute tutorial (Java) | https://cucumber.io/docs/guides/10-minute-tutorial/ | El primer proyecto de Cucumber con Java, de cero. Repasa lo del lab 01 con otro ejemplo. |
| Cucumber — Gherkin Reference | https://cucumber.io/docs/gherkin/reference/ | Todas las palabras clave, también `Regla` (*Rule*), que el curso no usa, y las traducciones al español. |
| Cucumber — Writing better Gherkin | https://cucumber.io/docs/bdd/better-gherkin/ | Escenarios declarativos frente a imperativos, con ejemplos. Es la base de la sección de documentación viva de la teoría 04. |
| Cucumber — Anti-patterns | https://cucumber.io/docs/guides/anti-patterns/ | Errores frecuentes: pasos acoplados entre sí, features que prueban la interfaz, demasiados detalles. |

## Dinámica sugerida

- El tutorial, antes del lab 01.
- *Writing better Gherkin* y *Anti-patterns*, antes del paso 3 del proyecto.
