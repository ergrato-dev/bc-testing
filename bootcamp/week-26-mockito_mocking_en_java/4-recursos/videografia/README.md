# Videografía - Semana 26

Los videos usan JUnit 5 y versiones anteriores de Mockito. Lo que muestran funciona igual con JUnit 6 y Mockito 5; la diferencia es la configuración del agente en el `pom.xml` ([teoría 01](../../1-teoria/01-mocks-y-stubbing.md)).

| Recurso | URL | Por qué verlo |
|---|---|---|
| Using Mockito with JUnit 5 (Code With Arho) | https://www.youtube.com/watch?v=p7_cTAF39A8 | Introducción a Mockito con `MockitoExtension`. |
| Mock, When and ThenReturn with Mockito (Aneesh Mistry) | https://www.youtube.com/watch?v=MztH6vkeFVk | `mock`, `when` y `thenReturn` paso a paso. |
| Mockito - Using Argument Matches in Java Unit Tests (HamletDRC) | https://www.youtube.com/watch?v=razPMCf66_0 | Matchers en stubs y en `verify`. |
| @Captor Annotation in Mockito with Example (KK JavaTutorials) | https://www.youtube.com/watch?v=4JhYjs9D37M | `ArgumentCaptor` y `@Captor` en un ejemplo corto. |

## Dinámica sugerida

- Ver los videos 1 y 2 antes del lab 01.
- Ver los videos 3 y 4 antes del lab 02.
