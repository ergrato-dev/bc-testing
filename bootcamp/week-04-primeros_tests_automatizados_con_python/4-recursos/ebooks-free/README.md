# Ebooks y lecturas gratuitas - Semana 04

| Recurso | Qué leer | Para qué |
|---|---|---|
| [pytest: Get Started](https://docs.pytest.org/en/stable/getting-started.html) | La página entera | Primer test, clases `Test*` y `pytest.raises`. Donde dice `pip install`, tú usas `uv add --dev` |
| [pytest: How to write and report assertions](https://docs.pytest.org/en/stable/how-to/assert.html) | «Assertions about expected exceptions» y «Making use of context-sensitive comparisons» | Cómo pytest reescribe el `assert` y por qué `match` es una expresión regular |
| [uv: Working on projects](https://docs.astral.sh/uv/guides/projects/) | Hasta «Running commands» | `uv init`, `uv add`, `uv.lock` y `uv run`, el recorrido de la teoría 01 |
| [Python: unittest](https://docs.python.org/3/library/unittest.html) | «Basic example» | El estilo `unittest` que verás en proyectos antiguos y que pytest ejecuta sin cambios |
| [The Practical Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html) | «Unit Tests» | Qué es un test unitario, igual en cualquier lenguaje |

## Orden sugerido

Get Started antes del lab 01; assertions antes del lab 02; el resto como consulta.
