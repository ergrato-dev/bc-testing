# Ebooks y Lecturas Gratuitas

## Seleccion recomendada

| Recurso | URL | Por qué leerlo |
| --- | --- | --- |
| Canon TDD - Kent Beck | https://newsletter.kentbeck.com/p/canon-tdd | El creador de TDD describe el flujo canónico: lista de escenarios, un test, hacerlo pasar, refactorizar y repetir. |
| The Cycles of TDD - Robert C. Martin | https://blog.cleancoder.com/uncle-bob/2014/12/17/TheCyclesOfTDD.html | Explica los ciclos anidados de TDD (de segundos a horas) y por qué el refactor es continuo y no algo para el final. |
| Definition Of Refactoring - Martin Fowler | https://martinfowler.com/bliki/DefinitionOfRefactoring.html | Definición precisa de refactor: cambiar la estructura interna sin alterar el comportamiento observable. |
| Self Testing Code - Martin Fowler | https://martinfowler.com/bliki/SelfTestingCode.html | Justifica por qué una suite automatizada confiable es la red de seguridad que hace posible refactorizar sin miedo. |

## Enfoque de lectura

- Como mantener ciclos cortos de feedback.
- Estrategias para refactor incremental con los tests en verde.
- Diseno emergente basado en comportamiento.
